## 🗂️ What Is This Project?

This repository contains a full BA artifact suite built for a **mobile insurance quoting app** — a greenfield product designed to let customers generate, compare, and bind insurance quotes entirely from their phone.

The project simulates an end-to-end Agile delivery engagement, from initial requirements elicitation through sprint planning, UAT execution, and defect remediation. Every artifact follows enterprise BA documentation standards and is structured to mirror what a BA would deliver on a real product team.

**This is not a coding project — it's a demonstration of BA craft.**

## 📋 Artifacts Included

### 1. Business Requirements Document (BRD)
A full BRD covering business objectives, scope, stakeholder register, functional and non-functional requirements, constraints, assumptions, and dependencies — written to be implementation-ready for a development team.

### 2. User Stories & Sprint Backlog (30+ Stories)
Epics broken into sprint-ready user stories following the **"As a / I want / So that"** format, each with:
- Detailed **acceptance criteria** (Given/When/Then)
- Story point estimates
- Priority ranking (MoSCoW)
- JIRA ticket structure with sprint assignment

**Key epics covered:**
- User Onboarding & Authentication
- Quote Generation & Premium Calculation
- Policy Comparison & Selection
- Billing & Payment Integration
- Notifications & Alerts

### 3. UAT Test Cases
Full UAT suite mapped directly to user stories and acceptance criteria, including:
- Step-by-step test scripts
- Expected vs. actual results columns
- Pass/Fail status tracking
- Linked defect IDs for failed cases

### 4. Requirements Traceability Matrix (RTM)
End-to-end traceability linking:
```
Business Requirement → User Story → Test Case → Defect (if applicable)
```
Ensures nothing falls through the cracks from requirements through QA sign-off.

### 5. BPMN Process Maps (As-Is / To-Be)
Visio/Lucidchart process flows documenting:
- Current-state quoting journey (manual, agent-assisted)
- Future-state mobile self-serve flow
- Decision gateways, system touchpoints, and handoff points

### 6. Figma Wireframe Prototype
Interactive low-fidelity prototype covering the core quoting flow — validated with stakeholders prior to development to reduce rework cycles.

→ **[View Figma Prototype](#)** *(link to be added)*

### 7. Finance Data Controls & Reconciliation
User stories affecting **premium calculation and billing flows** are mapped to data reconciliation checkpoints and financial control points — ensuring system changes preserve financial accuracy during releases.
